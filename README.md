# SHQAWA PRO | شقاوة برو

موقع عربي متجاوب لخدمات البرمجة والتطبيقات والتصميمات، مع مساعد دردشة يستخدم Gemini من خلال واجهة خلفية على Vercel.

## الملفات
- `index.html` واجهة الموقع.
- `style.css` التصميم والحركات والتجاوب مع الهاتف.
- `app.js` التفاعل والشات وتصفية نماذج الأعمال.
- `api/chat.js` نقطة اتصال خلفية آمنة نسبيًا تستدعي Gemini؛ لا تضع المفتاح في الواجهة.
- `vercel.json` إعدادات Vercel.

## النشر من الموبايل
1. فك ضغط الملف ZIP.
2. أنشئ مستودعًا جديدًا على GitHub باسم `shqawa-pro`.
3. ارفع **محتويات المجلد** إلى جذر المستودع (لا ترفع ملف ZIP فقط).
4. افتح Vercel وسجّل الدخول باستخدام GitHub، ثم `Add New → Project` واختر المستودع.
5. انشر المشروع. لا تحتاج إلى Build Command لموقع HTML مع Vercel Functions.
6. بعد النشر افتح إعدادات المشروع في Vercel: `Settings → Environment Variables`.
7. أضف متغيرًا اسمه `GEMINI_API_KEY` وقيمته مفتاحك الجديد من Google AI Studio. اختَر بيئة `Production` (ويمكن أيضًا Preview إذا احتجتها).
8. احفظ المتغير ثم أعد النشر `Deployments → ... → Redeploy`.
9. افتح الموقع واختبر زر «اسأل شقاوة AI».

## اختبار محلي
يتطلب Node.js 18 أو أحدث وVercel CLI أو بيئة تدعم Vercel Functions. ضع المفتاح في متغير البيئة `GEMINI_API_KEY` ولا تحفظه داخل ملفات الواجهة.

## مهم قبل الإعلان
- هذا المشروع يضم واجهة الموقع ونقطة API للشات. قسم الأعمال الحالي يحتوي نماذج شكلية، وليس أعمالًا حقيقية.
- رقم واتساب الموجود في الموقع هو `01020427153` وفق الرقم المحدد للمشروع؛ غيّره في `index.html` إن لزم.
- لا يوجد حتى الآن نظام إدارة أو قاعدة بيانات لحفظ المشاريع. لا ترفع بيانات حساسة في الموقع. يمكن إضافة لوحة إدارة حقيقية بعد ربط قاعدة بيانات ومصادقة.
- لا تضع مفتاح API في `index.html` أو `app.js` أو مستودع GitHub. استخدم متغير البيئة في Vercel.
- الاستخدام المجاني لـ Gemini محدود وقد يتغير حسب النموذج والحساب والمنطقة؛ راجع شروط Google AI Studio. هذا المشروع لا يفعّل فوترة ولا يضمن أن كل نموذج متاح مجانًا.
- أضف حماية إضافية/حدود استخدام على نقطة API قبل نشر الشات على نطاق واسع، لأن الزوار قد يستهلكون الحصة المتاحة.
