# SHQAWA PRO | شقاوة برو — Studio Edition

## الملفات
- `index.html`: الصفحة الرئيسية.
- `admin.html`: لوحة إضافة الأعمال واختيار القسم وإدارتها.
- `apps.html`: صفحة التطبيقات.
- `designs.html`: صفحة التصميمات والبنرات.
- `websites.html`: صفحة المواقع والمتاجر.
- `style.css`: التنسيقات والخلفية المتحركة.

## المزايا
- خلفية متحركة بتوهجات وجزيئات ضوئية.
- صفحة مستقلة لكل قسم.
- نموذج لإضافة مشروع واختيار القسم والوصف والصورة والرابط.
- بطاقات المشاريع تتحدث تلقائيًا في صفحات الموقع على نفس المتصفح.
- رقم التواصل 01020427153 وروابط واتساب والاتصال.

## مهم جدًا: حدود النسخة الحالية
لوحة الإضافة تحفظ البيانات والصور في `localStorage` داخل المتصفح فقط. هذا نموذج واجهة يعمل على نفس الجهاز والمتصفح، لكنه **ليس نظام نشر عام**؛ الزوار الآخرون لن يروا الأعمال المضافة من لوحة الإدارة، ولن تنتقل المشاريع بين الأجهزة. لكي تنشر مشاريعك للناس فعلًا، يجب ربط لوحة الإدارة بقاعدة بيانات وتخزين صور (مثل Supabase أو Firebase) مع صلاحيات دخول للإدارة. لا تضع مفاتيح سرية داخل ملفات HTML.
